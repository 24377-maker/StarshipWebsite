# StarshipWebsite
# Starship — SpaceX

A single-page website exploring SpaceX's Starship system — the full stack, the Super Heavy booster, and the Raptor 3 engine. Built as a Digital Technologies project (NCEA Level 1, AS92005).

**Live site:** https://24377-maker.github.io/StarshipWebsite/

## About

Starship is SpaceX's fully reusable launch system. This site breaks it down into three sections:

- **Overview** — hero landing section
- **System** — the Starship + Super Heavy stack, with full specs (thrust, payload, propellant, hull material)
- **Raptor 3** — the engine powering it, with design notes and performance stats
